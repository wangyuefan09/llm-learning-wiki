# Agent项目简历口径

## 简历版

**AI Agent智能工作台｜开发成员｜2025.08—至今**

**项目简介：** 面向企业复杂任务处理场景，建设通用 AI Agent 智能工作台，支持多轮对话、任务拆解、工具调用、浏览器与 Linux 桌面操作、文档协作、知识检索、多 Agent 协作、项目隔离及过程回溯，应用于研发辅助、文档处理、网页操作和知识问答等场景。

**技术栈：** Python、Flask、LiteLLM、LangChain、FastMCP、Playwright、FAISS、Docker、WebSocket

- **Agent运行与上下文编排：** 参与 Agent 执行框架建设，围绕多轮会话、Prompt 上下文、模型调用、工具分发与结果回填构建“决策—执行—观察—再决策”闭环，并通过分层历史压缩控制长任务上下文。
- **多环境工具执行：** 参与浏览器自动化、Linux 桌面、文件编辑、代码执行和文档查询等工具接入，统一工具参数、执行生命周期、结果回填与实时进度展示，使 Agent 能直接操作网页、桌面应用和工作区文件。
- **多Agent协作与任务拆解：** 参与父子 Agent 委派与并行任务机制建设，支持子任务独立上下文、Agent Profile 选择、结果回传、等待与取消，降低长链路任务对主 Agent 上下文的占用。
- **长期记忆与项目隔离：** 参与基于 Embedding + FAISS 的长期记忆召回及 Project 工作区建设，将指令、知识、文件、Memory、Variables、Secrets、MCP、Skills 和模型配置按项目隔离，提升跨轮任务连续性并减少上下文串扰。
- **扩展性与恢复能力：** 参与 Extension、Plugin、Skills 和 MCP 扩展体系建设，并结合运行日志、聊天持久化、历史压缩备份和 Time Travel 工作区快照，支持执行过程追踪、差异检查与文件回滚。
- **工程文档沉淀：** 建设项目中文文档体系，覆盖安装部署、使用指南、Browser、Desktop、Memory、Projects、MCP 等模块，并补充 Agent Profile 与运行时 Prompt 设计说明。

## 30秒介绍

> 我参与开发了一个通用 AI Agent 智能工作台，重点不是做单轮问答，而是让模型能够持续拆任务、调工具、读取结果并纠错。我主要参与 Agent Loop、上下文与工具编排，多环境工具、多 Agent、长期记忆和 Project 隔离，以及 Plugin、Skills、MCP 和工作区恢复能力。平台目前可以操作浏览器、Linux 桌面、文件、命令行和文档，并通过 WebSocket 实时展示执行过程。

## 1分钟介绍

> 这个项目面向企业复杂任务场景，目标是把模型从聊天助手变成能够操作真实工作环境的 Agent 平台。我参与的第一块是 Agent 运行闭环：用户消息进入 History，每轮组装项目指令、会话历史、记忆和环境状态，模型选择工具，工具结果回填后继续决策，直到完成。第二块是多环境工具，我们统一接入了 Playwright Browser、Linux Desktop、文件编辑、代码执行和文档查询。第三块是长任务能力，包括父子 Agent 委派、并行任务、分层 History 压缩、FAISS 长期记忆和 Project 隔离。第四块是扩展与恢复，通过 Skills、Plugin、MCP 接入外部能力，并用日志、聊天持久化和 Time Travel 快照支持过程检查与回滚。我还补充了项目中文文档和 Agent Profile/Prompt 设计说明。
