# Agent 如何真正「动手」？一篇看懂 Tool Calling

> [!info] 发布归档

## 内容提要

文章解释了 Tool Calling 在模型与业务程序之间的连接作用：应用把工具名称、描述和参数 Schema 交给模型，模型选择工具并生成参数；真正的 Java 方法、数据库查询或 HTTP 请求仍由应用执行，再把结果按 `tool_call_id` 写回上下文。

工具描述、粒度、参数校验和结构化返回会直接影响模型选择与后续协作。文章还区分了一次 Tool Calling 与 Agent Loop：前者规定一次动作怎样表示和执行，后者把多次动作与结果串成任务。代码中需要同时维护发送给模型的工具定义和保存真实实现的工具注册表，并保证两边名称一致。
