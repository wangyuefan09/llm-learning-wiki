# Agent 是如何思考的？一篇看懂 CoT、ReAct 和 Plan-and-Execute

## 内容提要

文章区分了三种常见方法：CoT 把复杂问题拆成中间步骤；ReAct 在判断、行动和观察之间循环；Plan-and-Execute 先生成整体计划，再逐步执行并在必要时重新规划。它们处在不同层级，可以组合使用，而不是三选一。

对于执行路径取决于实时结果的开放任务，ReAct 更合适；目标明确但链路较长时，可以先规划；步骤固定且不能改变顺序时，直接使用 Workflow。无论选择哪种方式，模型产生的计划和动作都要经过程序校验，状态、预算、人工确认与恢复能力也必须落在运行时中。
