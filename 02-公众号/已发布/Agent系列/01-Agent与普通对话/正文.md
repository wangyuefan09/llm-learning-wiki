# 什么是 AI Agent？从普通对话到任务执行

## 内容提要

文章从普通大模型聊天与 Agent 的差别讲起：聊天主要生成内容，Agent 则围绕目标读取上下文、选择工具、执行动作并根据结果继续推进。Agent 不是一种新模型，而是由模型与指令、工具、任务状态以及带停止条件的执行循环组成的应用系统。

文章还比较了 Tool Calling、Workflow 与 Agent：Tool Calling 表示一次结构化能力调用，Workflow 由代码预设路径，Agent 则能根据中间结果动态选择下一步。生产系统通常组合使用三者，并由后端负责权限、事务、幂等、超时、审计和高风险操作确认。
