# 拆开一个 AI Agent：LLM、工具、记忆和执行循环如何配合？

> [!info] 发布归档

## 内容提要

文章用 `AI Agent = LLM + 工具 + 记忆 + 执行循环` 拆解 Agent。LLM 决定当前一步做什么；工具连接 Java Service、数据库和外部接口；记忆保存上下文、任务状态及跨任务信息；执行循环负责调度每轮决策与执行，并判断继续、等待或结束。

日志分析示例展示了四部分如何连续协作。文章同时强调：指令只是模型判断的输入约束，不是权限系统；工具执行仍要做身份、权限、参数、幂等与回滚校验；任务状态应结构化保存；最大步骤数、超时和风险控制必须由程序强制执行。
