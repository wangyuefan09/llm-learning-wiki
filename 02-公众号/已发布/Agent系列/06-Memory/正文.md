# Agent 的 Memory 是什么？一篇讲清上下文、短期记忆和长期记忆

> [!info] 发布归档
> 公众号页面、作者和发布时间已核验。本地保留文章入口、内容提要与知识库关联；完整正文、代码排版和图片以[公众号原文](https://mp.weixin.qq.com/s?__biz=MzYzNTA1MzY1OQ==&mid=2247483753&idx=1&sn=b489b579ca102261585567d582aee2d7&scene=21#wechat_redirect)为准。

## 内容提要

文章把 Memory 定义为围绕模型运行的信息管理机制：保存状态、找回相关信息，并把结果放进当前上下文。上下文是单次模型调用能看到的输入；短期记忆服务当前会话或任务，保存消息、计划、工具调用和检查点；长期记忆跨会话保存经过筛选的偏好、事实、历史经验与规则。

文章强调“短期”描述作用范围，不等于只存在进程内存；短期状态可以持久化到 Redis、数据库或 Checkpointer。长期记忆也不是把全部聊天永久保存，而要按用户或项目隔离，记录来源和更新时间，支持更新、删除、去重与冲突处理。Memory 与 RAG 可以共享检索技术，但信息来源和写入过程不同。
