# 公众号创作流程

```text
记录灵感
→ 确定标题
→ 收集资料
→ 生成初稿
→ 学习与事实核验
→ 补充个人理解和项目实践
→ 去 AI 味
→ 生成配图
→ 人工校验
→ 发布
→ 沉淀到项目复盘与面试问答
```

## 1. 建立文章目录

```text
写作中/文章标题/
├── 正文.md
├── 资料.md
├── 配图.drawio
└── 配图/
```

创建时，将 [[公众号文章模板]] 复制为 `正文.md`，并建立 `资料.md`。

## 2. 生成初稿

```text
读取当前文章目录中的《资料.md》及其链接的学习笔记，围绕标题生成《正文.md》；
不添加资料中无法验证的事实，标记需要人工核验的结论，并保留来源链接。
```

## 3. 学习与核验

```text
根据《正文.md》和《资料.md》生成五个自测问题，暂时不要给出答案；
等我逐一回答后，检查理解并指出遗漏。
```

核对技术结论、代码、版本信息和引用，将自己的判断与实际项目结果补进正文。

## 4. 去 AI 味

```text
$article-humanizer-zh

处理当前文章目录中的《正文.md》，保留技术术语、代码、数据、来源链接、
个人判断和实践经历，重点处理模板化开场、重复总结、连续设问和说明书式表达。
```

## 5. 文章配图

```text
$article-diagram

读取当前文章目录中的《正文.md》，提取 2～4 个值得绘制的技术结构，
生成多页《配图.drawio》，并将导出文件保存到《配图》目录。
```

## 6. 发布后沉淀

- 将新增知识补充到学习笔记。
- 将项目相关内容补充到项目复盘。
- 生成三个递进式问题并补充到面试问答。
- 确认已经发布后，将文章目录移动到 `已发布/`。
