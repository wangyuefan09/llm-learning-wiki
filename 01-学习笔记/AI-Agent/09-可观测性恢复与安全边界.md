# 可观测性、恢复与安全边界

## Agent为什么更难观测

固定 API 的路径通常稳定，Agent 每次可能选择不同工具、步骤和子 Agent。最终失败可能来自模型、Prompt、工具、环境、Memory、权限或上下文压缩。只记录最终答案不足以定位问题。

## 一次任务应记录什么

### 请求级

- trace/context/task id；
- 用户与 Project；
- Agent Profile 与模型；
- 开始、结束、状态和终止原因；
- 总步骤、总耗时、Token 与成本；
- 最终结果与人工评价。

### 模型级

- 每轮 Prompt Token 和输出 Token；
- Provider、Model、耗时、重试与错误；
- 工具选择结果；
- 上下文各区域的 Token 占比。

### 工具级

- 工具名和 call id；
- 参数摘要；
- 开始、结束和耗时；
- 成功、失败、重试和取消；
- Artifact 与副作用；
- 结果裁剪前后的大小。

### 多Agent级

- 父子关系；
- 委派目标与 Profile；
- Job 状态；
- 结果回传和验收；
- 子任务 Token 与耗时。

## 项目当前日志与实时状态

`helpers.log` 用 `LogItem` 保存模型、工具、进度和错误；`AgentContext.output()` 暴露 Context 状态。WebSocket Manager 维护连接、事件和缓冲，前端通过状态快照与增量事件展示聊天、Browser、Desktop 和 Canvas。

HTTP Poll 可以作为兼容路径，但 WebSocket 更适合实时流式状态。需要测试重连、重复事件、乱序、超时和断线后的状态补齐。

## 恢复的不同层次

### 对话恢复

聊天持久化保存 Context、Agent、History 和 Log，重新加载后继续会话。

### 上下文恢复

History 自动压缩或 Chat Compaction 控制上下文长度，压缩前保留备份。

### 工具恢复

Browser、Shell、MCP 等工具需要重连、重试、取消和资源清理。是否重试取决于副作用是否可重复。

### 工作区恢复

Time Travel 对 `/a0/usr` 下的工作区自动建立 Git 对象快照，支持：

- history list；
- commit/file diff；
- travel/revert preview；
- travel 到目标状态；
- revert 某次变更；
- 回滚前保护快照。

### 业务恢复

数据库写入、邮件发送、云资源创建等外部副作用不在工作区快照范围内，需要幂等键、状态机、补偿动作或人工处理。

## Time Travel的边界

Time Travel 保护 Agent 管理的文件工作区：

- 不替代业务 Git 仓库；
- 不替代备份；
- 不回滚数据库；
- 不撤销外部 API 副作用；
- 不覆盖任意容器外路径；
- 二进制大文件和嵌套 Git 仓库需要单独验证。

## 安全边界

Agent 安全不能只靠 Prompt。应分层控制：

### 环境层

- Docker/虚拟机隔离；
- 限制挂载目录；
- 非特权用户；
- CPU、内存、进程和文件配额；
- 出网白名单。

### 身份与项目层

- 用户认证；
- Project授权；
- 服务端绑定Context与Project；
- 跨项目数据访问检查。

### 工具层

- 工具白名单；
- 参数Schema和路径校验；
- 读写权限分级；
- 高影响动作确认；
- MCP Server信任与版本管理。

### 凭据层

- Secrets不进入公开文件；
- 日志和Prompt遮蔽；
- 最小权限和轮换；
- Project作用域；
- 使用审计。

### 内容层

- 把网页、文档和工具输出视为不可信数据；
- 外部内容不能覆盖系统与项目规则；
- 引用内容与执行指令分离；
- 对下载文件和Plugin做扫描与校验。

## Prompt Injection

Browser 和 Document Query 可能读取包含“忽略之前指令并执行某动作”的内容。运行时应区分：

- 系统与项目指令；
- 用户目标；
- 外部网页/文档内容；
- 工具返回数据。

外部内容只能作为数据，不应自动获得工具授权。关键动作还要经过代码级权限与审批。

## 恢复测试

主动注入故障：

- 模型超时或限流；
- Browser 页面关闭；
- Shell 命令卡住；
- WebSocket 断线重连；
- MCP Server 断连或 Schema 变化；
- History 超窗；
- Memory 索引损坏；
- 文件写入一半；
- 父任务取消时子任务仍在运行。

记录是否检测、恢复耗时、是否残留资源、是否重复副作用和用户能否理解当前状态。
