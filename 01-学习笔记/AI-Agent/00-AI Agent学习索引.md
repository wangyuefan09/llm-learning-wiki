## 主线问题

这部分学习围绕一个问题展开：怎样把大模型从一次性回答者变成能够在真实环境中持续完成任务的执行系统？

需要依次回答：

- Agent 与普通聊天、固定 Workflow 有什么区别？
- 模型输出如何变成可执行 Tool Call？
- 工具结果如何回到模型并形成闭环？
- 长任务中的状态、上下文和记忆如何管理？
- 什么时候拆子 Agent，如何控制并行和成本？
- Skills、Plugin、MCP 分别解决什么扩展问题？
- Browser、Desktop、Shell 等有状态工具如何与会话绑定？
- 如何评估成功率、稳定性、成本和安全边界？
