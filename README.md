# 个人大模型知识库

这个知识库服务于一个明确目标：系统学习大模型知识，完成 RAG 与 AI Agent 项目复盘，并通过微信公众号文章检验学习成果。

## 知识流转

```text
快速记录 → 资料收集 → 学习笔记 → 公众号文章 → 项目复盘 → 面试问答
```

## 日常入口

- 临时想法、话术、问题和链接：[[快速记录]]
- 本周唯一目标：[[学习看板]]
- 完整学习顺序：[[学习路线]]
- 公众号备选主题：[[选题池]]
- 文章生产步骤：[[公众号创作流程]]

## 使用约定

1. 捕捉内容时只写入 `00-灵感与收集/快速记录.md`，不要边记录边分类。
2. 每周整理一次快速记录，将内容转移到话术库、选题池、网页收藏或学习笔记。
3. 每篇公众号文章在 `02-公众号/写作中/文章标题/` 下建立独立目录。
4. 文章目录只维护 `正文.md`、`资料.md`、`配图.drawio` 和 `配图/`；正文历史由 Git 保存。
5. 完整项目源码放在独立 GitHub 仓库，本知识库只保存源码链接、项目理解、实验记录和面试问答。
6. 只有文章实际发布后，才将目录移动到 `02-公众号/已发布/`。

## GitHub 远端

本地仓库初始化后，在 GitHub 创建同名私有仓库并执行：

```bash
git remote add origin git@github.com:你的用户名/个人大模型知识库.git
git push -u origin main
```
